# Security Policy

## Supported Versions

The following versions of `subtitle-tools` are currently receiving security updates:

| Version | Supported          |
| ------- | ------------------ |
| 0.1.x   | Yes                |

## Reporting a Vulnerability

If you discover a potential security vulnerability within `subtitle-tools`, please do not report it publicly via GitHub issues.

Instead, please send a report to:
`118852217+YusufBeratZengin@users.noreply.github.com`

Include the following details in your report:
- A description of the issue and potential impact
- Steps to reproduce the issue or proof-of-concept files
- Any potential mitigations or suggested fixes

You should receive an acknowledgment within 48 hours. If the vulnerability is confirmed, a security patch will be released promptly.
